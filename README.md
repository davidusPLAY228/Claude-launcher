# Возможности приложения

### 🧭 Главный экран настроек

| Поле | Описание |
|---|---|
| **Адрес API** | Полный URL OmniRoute API (например: `http://192.168.1.100:20129`) |
| **Auth Token** | API ключ для Claude Code (с маскировкой, кнопка 👁 для отображения) |
| **Model** | Выбор модели из списка или ввод кастомной (через `Custom...`) |
| **Рабочая папка** | Директория проекта для запуска Claude Code |

### 🔍 Панель зависимостей

Автоматическая проверка установленных компонентов с индикацией:

- 🟢 **Установлен** — версия отображается, всё готово к запуску
- 🟡 **Неправильная версия** — Node.js версии отличается от рекомендуемой (v22.22.2)
- 🔴 **Не установлен** — показывается кнопка "Установить"

| Зависимость | Установка | Рекомендация |
|---|---|---|
| **Node.js** | Вручную через [nvm](https://www.nvmnode.com/ru/guide/download.html) | v22.22.2 |
| **OmniRoute** | `npm install -g omniroute` | Последняя версия |
| **Claude Code** | `winget install Anthropic.ClaudeCode` | Последняя версия |

### 📂 Sidebar (боковая панель)

| Кнопка | Действие |
|---|---|
| ☰ | Развернуть/свернуть сайдбар |
| ▶ / ⏸ | Запустить/остановить OmniRoute |
| 📥 | Открыть страницу установки NVM |

### 📊 Экран логов

Показывает выполнение всех этапов запуска:

1. **P1: Применение настроек** — валидация конфигурации
2. **P2: Открытие OmniRoute** — проверка доступности API и запуск сервера
3. **P3: Открытие папки** — подтверждение рабочей директории
4. **P4: Открытие Claude** — запуск Claude Code в PowerShell

**Индикация состояния:**
- ⏳ Жёлтая граница — выполняется
- ✅ Зелёная граница — успешно
- ❌ Красная граница — ошибка

**Кнопки управления:**
- **← Назад** — вернуться к настройкам
- **Stop** — остановить все процессы
- **Повторить** — перезапустить при ошибке

## Установка

### Способ 1: Portable (без установки)

1. Скачайте архив с последней версией из [Releases](https://github.com/Hachiba9020/claude-launcher/releases)
2. Распакуйте в любую папку
3. Запустите `Claude-launcher.exe`

### Способ 2: Установщик

1. Скачайте `Claude-launcher-Setup.exe` из [Releases](https://github.com/Hachiba9020/claude-launcher/releases)
2. Запустите установщик
3. Приложение установится в `C:\Users\%USERNAME%\AppData\Local\Claude-launcher`
4. Создайте ярлык на рабочем столе через контекстное меню

## Сборка из исходников

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка portable версии
npm run package

# Сборка установщика
npm run make

# Сборка обеих версий (x32 + x64)
npm run make:both
```

### Управление процессами

**Запуск OmniRoute:**
1. Парсинг `apiUrl` → извлечение `host` и `port`
2. Обновление файлов `.env`:
   - `~/.omniroute/.env`
   - `node_modules/omniroute/.env`
3. Создание PowerShell скрипта `launch-omniroute.ps1`
4. Запуск через `cmd.exe /c start` с заголовком окна
5. Ожидание доступности порта (30 сек таймаут)

**Запуск Claude Code:**
1. Генерация `run-claude.ps1` с environment variables:
   - `ANTHROPIC_API_KEY`
   - `ANTHROPIC_BASE_URL` (apiUrl + `/v1`)
   - `ANTHROPIC_MODEL`
   - `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1`
2. Запуск через `powershell.exe -NoExit -File`
3. Процесс остаётся `detached` для независимой работы

**Остановка процессов:**
1. PowerShell скрипт получает список процессов через `Get-CimInstance`
2. Фильтрация по `CommandLine` (поиск `omniroute` и `run-claude.ps1`)
3. Завершение через `taskkill /pid <pid> /T /F`
4. Закрытие родительских терминалов (cmd.exe/powershell.exe)

## Требования

- **Windows 10/11** (x64 или x32)

- **OmniRoute** (устанавливается через `npm install -g omniroute`)
- **Claude Code** (устанавливается через `winget install Anthropic.ClaudeCode`)
